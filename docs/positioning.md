# 課題設定：東京で「自分が本当に行ける避難先」が分からない要配慮者

「だれでも避難ナビ TOKYO」は、**東京全域の、あらゆる要配慮者**が直面する普遍的な課題に答えるサービスです。地域・災害種別を限定しません。本ドキュメントは、その課題設定（誰の・どんな課題に答えるか）を一次情報に基づいて示します。

## 普遍的な課題：要配慮者は「行ける避難先」を平時に把握できない

既存の避難所案内の多くは、移動に制約のない人を前提にしています。しかし——

- 車椅子・高齢・乳幼児連れ・視覚/聴覚障害・オストメイト・要介護・外国語など、**配慮が必要な人**にとっては「最寄り」が「行ける」とは限りません（段差・浸水域・夜間・天候・設備の有無）。
- 災害は洪水・高潮・津波・土砂・地震・火災と多様で、**同じ避難所でも災害種別により適否が変わります**。
- 結果として当事者は「**自分（や家族）が、今いる場所から、本当に行ける避難先はどこか**」を平時に把握すること自体が大きな壁になっています。

この課題は東京のどの地域・どの災害でも生じます。本サービスは特定地区に絞らず、**東京全域 × 複数災害 × あらゆる配慮属性**を対象にします。

## 最も切実な代表ケース：江戸川区（江東5区）の大規模水害

汎用設計のうえで、**最も切実な検証シナリオ**として江戸川区の水害を重視しています（対象を限定するものではありません）。

- 江戸川区は川と海に囲まれ **陸域の約7割がゼロメートル地帯**。江東5区（江戸川・江東・墨田・葛飾・足立）では **2週間以上水が引かないエリアに約100万人が居住**。
- 区内に **要配慮者 約26万人**、**避難行動要支援者 約5,800人**。国（内閣府）の **個別避難計画作成モデル事業** の対象区。
- 「誰が・どこへ・どう逃げるか」の具体化が全国的に難航しており、当事者支援の価値が最も高い地域の一つ。

## 本サービスが答えること（東京全域で）

| 要配慮者が直面する壁 | 本サービスの機能 |
|---|---|
| 想定災害の把握が難しい | 洪水/高潮/津波/土砂のハザード（国交省）を地図に重ねて可視化 |
| その災害で「使える」避難先が分からない | 避難場所の**災害種別フラグ**で、想定災害に対応した避難先を優先 |
| 自分が行けるか分からない | 車椅子・高齢・乳幼児・視覚/聴覚・オストメイト等の属性で**バリアフリー適合を再ランキング** |
| 近いが危険・行きにくい避難先を選ぶ | **「より近いのに見送った理由」**（浸水域・段差等）を提示し当事者の判断を支援 |
| 何を・いつすればいいか分からない | 属性×災害×推奨先から**マイ・タイムライン**（内閣府の警戒レベル準拠）を生成 |
| 避難後の生活が不安 | 給水拠点・公衆Wi-Fi、（水害時は）建物高さによる**垂直避難先**を地図に重ね |
| 日本語が不自由 | やさしい日本語・英語・中国語、音声入力・読み上げに対応 |

## 対象範囲と正直な限界
- 🟢 **東京全域対応**: 避難所/避難場所（63市区町村）・トイレ設備・給水拠点・公衆Wi-Fi・ハザード・3D地形・マイ・タイムライン・多言語
- 🟡 **23区中心（データ元の制約）**: PLATEAU建物3D（23区のみ）・都営バス停（都営バス＝23区中心）。多摩・島嶼は今後の拡張
- 福祉避難所（二次避難所）の座標付き網羅データは東京都に存在せず未統合（Issue #4）。高齢化率は市区町村粒度（町丁目化は Issue #6）

## デモシナリオ
1. 「雨の日、車椅子の母と避難したい。介助は私がします」→ 屋内・バリアフリー・近距離を優先、天候を加味
2. 「夜に、目の不自由な父と逃げる」→ 点字ブロック・屋内・近距離・夜間の安全を加味
3. 「ベビーカーと0歳の子ども連れ」→ 段差の少ない屋内＋近傍のおむつ替え台
4. 「江戸川区で水害が心配。車椅子の母と避難したい」→ 洪水対応かつバリアフリーな避難先を優先、洪水ハザード自動表示（最も切実な代表ケース）
5. どの地域・どの災害でも、近いが危険な避難先は「行けない理由」付きで降格し、より安全な避難先を推奨

## 審査軸との対応
- **アイデア力 / ソーシャルインパクト**: 「最寄り≠行ける」という要配慮者の**普遍的課題**に、東京全域・命に直結する形で答える。最も切実な例として江東5区100万人・避難行動要支援者5,800人の大規模水害を実証
- **オープンデータ活用**: 避難所×トイレ設備×ハザード×高齢化率×給水/Wi-Fi×建物高さ×バス停を掛け合わせ「単独データでは出せない"行ける順"」を提示
- **サービスデザイン**: 当事者がことばで相談でき、根拠（なぜ1位か・行けない理由）とマイ・タイムラインまで返す。多言語・音声で言語や視覚の壁も下げる
