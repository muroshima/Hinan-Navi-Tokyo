# 課題設定：江戸川区の大規模水害における要配慮者の避難

「だれでも避難ナビ TOKYO」は、**特定自治体の実課題への回答**として設計しています。本ドキュメントは、その課題設定（誰の・どんな課題に答えるか）を、一次情報に基づいて示すものです。

## 対象：江戸川区（江東5区）の大規模水害

江戸川区は、川と海に囲まれ **陸域の約7割がゼロメートル地帯** という、首都圏でも最も水害リスクの高い地域のひとつです。荒川・江戸川の氾濫など大規模水害時には広範囲・長期間の浸水が想定され、**江東5区（江戸川・江東・墨田・葛飾・足立）では2週間以上水が引かないエリアに約100万人が居住**しています。

このため江戸川区は、浸水想定区域外（区外）への **自主的広域避難・分散避難** を推奨しています（江東5区大規模水害対策協議会「犠牲者ゼロの実現に向けて」）。

### 最も難しいのが「要配慮者の避難」
- 江戸川区には **要配慮者（高齢者・障害者・難病患者など）が約26万人**、うち地域防災計画上の要配慮者が約7.2万人、**避難行動要支援者が約5,800人** 在住。
- 国（内閣府）の **個別避難計画作成モデル事業** の対象区でもあり、「誰が・どこへ・どう逃げるか」を一人ひとり具体化する取り組みが進む一方、計画づくりは全国的に難航している。
- 当事者にとって、**「自分（や家族）が、今いる場所から、本当に行ける避難先はどこか」** を平時に把握すること自体が大きな壁になっている。

## 本サービスが答えること

「だれでも避難ナビ TOKYO」は、当事者が **ことばで状況を伝えるだけ**で、東京都オープンデータをもとに **「その人が本当に行ける避難先」** を提示します。江戸川区の課題に対して、具体的には次のように効きます。

| 江戸川区の課題 | 本サービスの機能 |
|---|---|
| 浸水想定の把握が難しい | 洪水ハザード（国交省）を地図に重ね、ゼロメートル地帯の浸水想定を可視化 |
| 洪水時に「使える」避難先が分からない | 避難場所の**災害種別フラグ**で、洪水時に避難できる指定緊急避難場所を優先 |
| 要配慮者が行けるかが分からない | 車椅子・高齢・乳幼児・視覚/聴覚・オストメイト等の属性で**バリアフリー適合を再ランキング** |
| 近いが危険な避難先を選んでしまう | **「より近いのに見送った理由」**（浸水域内・段差等）を提示し、当事者の判断を支援 |
| 個別避難計画づくりの入口がない | 自然文の相談から「行ける避難先＋理由＋経路」を出力し、計画づくりの**たたき台**にできる |

## 正直な限界（今後の拡張）
- 江戸川区が推奨する **区外への広域避難先** は、本作の現行データ（都内の指定避難所・避難場所が中心）では十分に扱えていません。**福祉避難所（二次避難所）データの統合（Issue #4）** と **広域避難先の取り込み**で対応予定です。
- 高齢化率は現状**市区町村粒度**（住民基本台帳 年齢別）。町丁目粒度への精緻化は **BigQuery空間結合（Issue #6）** で対応予定。

## デモシナリオ（江戸川区を想定）
1. 「江戸川区で水害が心配。車椅子の母と避難したい」→ 洪水対応かつバリアフリーな避難先を優先提示、洪水ハザードを自動表示
2. 「夜に、目の不自由な父と逃げる」→ 点字ブロック・屋内・近距離を重視、夜間の安全を加味
3. 浸水域内の近い避難所は「行けない理由」付きで降格し、より安全な避難先を推奨

## 審査軸との対応
- **アイデア力 / ソーシャルインパクト**: 「江東5区100万人・江戸川区の避難行動要支援者5,800人」という具体的・命に直結する課題に、当事者視点で答える
- **オープンデータ活用**: 避難所×トイレ設備×ハザード×高齢化率の掛け合わせで「単独データでは出せない"行ける順"」を提示
- **サービスデザイン**: 当事者がことばで相談でき、根拠（なぜ1位か・行けない理由）まで返す
