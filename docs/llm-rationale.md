# なぜ生成AIか — LLM抽出の技術的合理性

> 派手さより**筋の良さ**。本サービスにおける生成AIの役割・境界・フォールバックを、実装（`app/api/triage/route.ts` / `lib/gemini.ts` / `lib/triageFallback.ts`）に忠実に説明する。

## LLMに任せること / 任せないこと（設計の要）

```
自然文  ──[生成AI: 抽出のみ]──▶  構造化属性(JSON)  ──[決定論的スコアリング]──▶  避難先ランキング
「雨の日、車椅子の母と            {wheelchair:true,               lib/ranking.ts
  避難したい。介助は私」            has_caregiver:true,            (score = Σ 加減点)
                                  bad_weather:true, hazard:...}
```

- **生成AIは「自然文 → 構造化属性」の抽出だけ**に使う。
- **避難先の順位付けは決定論的なスコアリング**（`lib/ranking.ts`。基準点＋距離＋災害種別適否±バリアフリー±状況補正）で行い、**LLMを判断の中枢に置かない**。
- これにより結果は**説明可能・再現可能**（同じ入力→同じ順位、根拠を点数内訳で提示）。命に関わる判断をブラックボックス化しない。

## なぜ抽出に生成AIが必要か（ルールベース/フォームの限界）
入力例「**雨の日、車椅子の母と避難したい。介助は私がします**」から、以下を同時に読み取る必要がある:

| 抽出項目 | この文からの解釈 | ルールベースが苦手な理由 |
|---|---|---|
| `wheelchair` | 「車椅子の母」→ true | **主語が本人でなく同行者**（母）でも配慮要件は立つ |
| `has_caregiver` | 「介助は私が」→ true | 婉曲・省略表現の含意 |
| `bad_weather` | 「雨の日」→ true | 「荒天」「台風」「大雨」等の**表現ゆれ** |
| `hazard` | 明示なし → none（雨から水害を推測しすぎない） | **過剰推論の抑制**が必要 |
| `location` | 地名があれば出発地に | 文中の任意位置の固有表現 |

11の配慮属性（車椅子/高齢/乳幼児/視覚障害/聴覚障害/外国語/介助者/オストメイト/重度介護/夜間/天候）＋想定災害＋出発地を、**表現ゆれ・複合・同行者主語・婉曲**を含む自由文から拾うのは、キーワード辞書やフォームUIでは取りこぼす。生成AIの言語理解が最も効くのはこの「意味の構造化」である。

## 実装（Vertex AI Gemini・構造化出力＋検証）
- モデル: **Vertex AI Gemini（`gemini-2.5-flash`）**、IAM認証（APIキー不要）。
- **構造化出力**: `responseMimeType: application/json` ＋ `responseSchema`(OpenAPI風・全項目 required・hazardはenum)で**出力の形を固定**。
- **二重の型安全**: 受け取ったJSONを **zod** で再検証（`AttrsSchema`）。スキーマ不一致は不正として扱う。
- LLMの自由生成が下流（地図描画・スコア）に流れ込む余地を、スキーマ＋zodで塞いでいる。

## 誤抽出・障害時のフォールバック（止まらない防災）
命に関わるサービスは「AIが落ちても動く」ことが要件。多層のフォールバックを実装:

1. **認証・プロジェクト未設定**（`getGeminiClient()` が null）→ 語句一致抽出（`lib/triageFallback.ts`）
2. **Gemini呼び出しが例外**（権限/モデル/ネットワーク）→ catch して語句一致抽出
3. **出力がzod検証に失敗**（想定外の形）→ 語句一致抽出
4. **クライアントがオフライン**（`/api/triage` 到達不可）→ ブラウザ内の語句一致fallbackで検索を成立（避難所データはService Workerでキャッシュ済み）

いずれの経路でも `source`（`gemini` / `fallback` / `offline`）を返し、UIで抽出手段を明示する。**AIは「精度を上げる強化装置」であり、可用性の単一障害点ではない**。

## コスト・悪用対策（[#30]）
- `/api/triage`・`/api/timeline` は **IP単位レート制限（15回/分）＋同一入力の10分キャッシュ**でGemini呼び出しを抑制（`lib/rateLimit.ts`）。
- 出力はスキーマ固定のためプロンプトインジェクションでも任意の危険出力に至らず、最悪でも属性誤抽出→フォールバックに留まる。

## まとめ（効く評価軸: 技術力）
- 生成AIを**抽出という得意領域に限定**し、判断は決定論的・説明可能に保つ。
- **構造化出力＋zod＋多層フォールバック**で、精度と可用性（止まらないこと）を両立。
- これは「AIを使うこと」自体が目的ではなく、**要配慮者の自由な語りを、正確で行動可能な避難先提示に変換する**ための、筋の通った選択である。
